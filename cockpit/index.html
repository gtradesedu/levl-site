04 · FAQ
Do I need Levl Up to use the Cockpit? +
No. They are separate products and neither requires the other. The Cockpit does not care which strategy or indicator you trade.
Will it stay free? +
The core journal will. It opens free, no card and no countdown, and I have no interest in taking that away from anyone who has built a habit on it. Whatever else the Cockpit grows into, I would rather build it properly first than announce prices for things that do not exist yet.
Is there an app for my phone? +
Yes. The Cockpit installs to your home screen straight from the browser and then behaves like a normal app, full screen. No app store, no download, and it works the same on iPhone and Android. It needs a connection to open; your data is held on the device as well, so it loads instantly once it is up. Native App Store versions come later.
Which brokers can I import from? +
Any that export a CSV. The importer detects the delimiter, matches German and English column names, handles Kauf/Verkauf and Buy/Sell, and maps contract symbols like “NQ 09-26” back to NQ. If a file will not map, send it to help@levlhq.com and I will add it.
What happens to my data if I stop using it? +
Export it as a single file before you go. It contains every trade, note and setting, images included, and it opens without an account. Settings has a delete button that removes the cloud entry, every stored image and the account itself, with no copy left on our side.
Why should I trust a journal from a one-person company? +
Because the export button is the answer to that question, and it has no conditions on it. Everything I could use to lock you in (your data, the price, a required subscription) is deliberately absent.
